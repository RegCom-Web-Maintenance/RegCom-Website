Web Sub-Branch Onboarding

How to Add Your Own Mini-Game

Welcome to the RegCom Web team! Adding a game to the Web Branch Showcase takes only 2 steps and is a fun way to practice creating modules and opening your first Pull Request on GitHub.

Step 1 Create your game file in js/games/

Duplicate js/games/_template.js (or copy the starter code below) and save it as js/games/yourGameName.js.

js/games/yourGameName.js 
export default {
  id: "my-game",
  title: "Name of Your Game",
  author: "Your Full Name",
  authorRole: "Web Sub-Branch Member (Year & Course)",
  description: "Short 1-sentence instruction on how to play.",

  mount(container) {
    // Render your game's HTML inside `container`
    container.innerHTML = `
      <div style="text-align:center; padding: 2rem;">
        <h3>My Awesome Game 🎮</h3>
        <button class="btn btn-primary" id="play-btn">Click Me!</button>
      </div>
    `;

    // Attach your event listeners
    const btn = container.querySelector("#play-btn");
    btn.addEventListener("click", () => alert("Kumusta, Atenista!"));

    // Optional: return a cleanup function (e.g. clearInterval) when switching tabs
    return () => {};
  }
};
Step 2 Register your game in js/games/index.js

Open js/games/index.js, import your file at the top, and add it to the games array. The website will automatically create a tab and display your credits! 

import minesweeper from "./minesweeper.js";
import myGame from "./yourGameName.js"; // 1. Import your file

export const games = [
  minesweeper,
  myGame // 2. Add it to the list!
];
